# ニュースまとめ（RSS リーダー + メール通知）

feedly のように RSS / Atom フィードを集めて読む Web アプリです。新着記事はメールで受け取れます。

- **ジャンル別の記事一覧**：経済・ビジネス・ベンチャー・テック・AI・株・仮想通貨のおすすめフィードを最初から登録済み
- **未読管理と「あとで読む」**：記事を開くと既読になり、★を付けた記事は「あとで読む」に残る。キーワード検索もできる
- **フィード追加**：サイトの URL を入れるだけで RSS を自動で探す。ジャンルはいつでも追加・変更できる
- **メール通知**
  - 定時ダイジェスト：指定した時刻（初期値は 7:00 と 18:00）に、前回以降の新着をジャンル別にまとめて送る
  - キーワード通知：登録したキーワード（例：「ビットコイン」「上場」）を含む記事が出たらすぐ送る
- **OPML の入出力**：feedly など他の RSS リーダーとフィード一覧をやり取りできる
- スマホ表示とダークモードに対応
- **サーバー不要の通知モード**：GitHub Actions（無料）で、PC を閉じていても通知メールが届く

使うのは無料のサービスだけです：Gmail（メール送信）、GitHub Actions（自動実行・任意）、Tailscale（スマホから見る場合・任意）。

## 仕組み

```
[RSS フィード] --(30分ごと)--> 取得・重複除去 --> SQLite
                                          |--> キーワード一致 → すぐメール
                                          |--> 定時 → ダイジェストメール
                                     Web 画面（FastAPI）で閲覧・管理
```

Python（FastAPI + SQLAlchemy + feedparser + APScheduler）で作った 1 プロセスのアプリです。DB は SQLite のファイル 1 つだけです。

## はじめかた

### 1. Gmail の送信設定（無料）

1. Google アカウントで [2 段階認証](https://myaccount.google.com/security) を有効にする
2. [アプリパスワード](https://myaccount.google.com/apppasswords) を発行する（16 文字）
3. `.env.example` をコピーして `.env` を作り、`SMTP_USER`（Gmail アドレス）と `SMTP_PASSWORD`（アプリパスワード）、`MAIL_TO`（通知先）を入れる

Gmail 以外の SMTP（Outlook、さくらのメールなど）も、`SMTP_HOST` と `SMTP_PORT` を変えれば使えます。ポート 465 なら SSL、それ以外は STARTTLS で接続します。

### 2. 起動

**Python で起動する場合**（Python 3.11 以上）

```bash
python -m venv .venv
source .venv/bin/activate          # Windows は .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

**Docker で起動する場合**

```bash
docker compose up -d
```

ブラウザで http://localhost:8000 を開きます。起動するとすぐ 1 回目の取得が始まります。

### 3. 画面での設定

- **通知設定**：通知先アドレス、ダイジェストの時刻、キーワードを設定し、「テストメールを送る」で届くか確認する
- **フィード管理**：フィードの追加・削除・ジャンル変更を行う。URL が変わって取れなくなったフィードには「取得エラー」が表示される

> 初回の取得分は通知済みとして扱います（登録直後に数百件のメールが届かないようにするため）。メールで届くのは 2 回目以降の取得で見つかった新着です。

## ジャンル・サイトを追加するには

- 画面の「フィード管理」で、サイトの URL を入力して追加します。「または新しいジャンル」に名前を入れると、ジャンルも同時に作れます。
- 公式 RSS がない分野は、**Google ニュースの検索 RSS** を使うのが手軽です。
  `https://news.google.com/rss/search?q=キーワード&hl=ja&gl=JP&ceid=JP:ja`
- 初期登録するおすすめフィードを変えたいときは、`app/presets.py` を編集します。

## PC を閉じていても通知を受け取る（GitHub Actions）

サーバーを借りずに、GitHub Actions（GitHub の無料の自動実行機能）で「30 分ごとに取得 → キーワード通知 → 定時ダイジェスト」を動かせます。Web 画面は使わず、メール通知だけを行うモードです。

### 設定手順

1. GitHub のこのリポジトリで **Settings → Secrets and variables → Actions** を開く
2. **Secrets** タブに次を登録する（暗号化して保存され、ログにも表示されない）

   | 名前 | 内容 |
   |---|---|
   | `SMTP_USER` | 送信に使う Gmail アドレス |
   | `SMTP_PASSWORD` | Gmail のアプリパスワード |
   | `MAIL_TO` | 通知先のメールアドレス |
   | `NOTIFY_KEYWORDS` | キーワード通知の言葉（カンマ区切り。例：`ビットコイン,上場,OpenAI`）。不要なら登録しない |

3. **Variables** タブに次を登録する

   | 名前 | 内容 |
   |---|---|
   | `NOTIFY_ENABLED` | `true`（これを入れるまで自動実行は止まっています） |
   | `DIGEST_TIMES` | ダイジェストの時刻（省略すると `07:00,18:00`） |

4. **Actions** タブ → 「ニュース通知」→ **Run workflow** で 1 回手動実行し、緑のチェックになることを確認する

あとは 30 分ごとに自動で動きます。1 回目の実行で取った記事は通知済みとして扱うので、メールが届くのは 2 回目以降の新着からです。

### 購読するサイトを変えるには

リポジトリ直下に `feeds.opml` を置くと、そこに書かれたフィードだけを購読します（ない場合はおすすめフィードを購読）。Web 画面の「フィード管理 → OPML をダウンロード」で作ったファイルを、そのまま `feeds.opml` という名前でコミットするのが簡単です。

### 知っておくこと

- **費用**：公開リポジトリなら GitHub Actions は無料・無制限です。非公開（private）にした場合は月 2,000 分まで無料なので、`.github/workflows/notify.yml` の `cron` を `"7 * * * *"`（1 時間ごと、月約 720 分）に変えてください。
- **公開リポジトリの場合**：コードと実行ログは誰でも見られます。メールアドレス、パスワード、キーワードは Secrets に入れ、ログにも出さない作りにしています。ただし、どのサイトを購読しているか（`feeds.opml`）は見えます。気になる場合はリポジトリを非公開にしてください（Settings → General → Change visibility）。
- **定期実行が止まる場合**：公開リポジトリで 60 日間コミットがないと、GitHub が定期実行を自動で止めます。止める前に GitHub からメールが届くので、Actions タブで再度有効にしてください。
- **時刻のずれ**：GitHub の混雑状況によって、実行が数分〜数十分遅れることがあります。

## Web 画面をスマホから見るには（Tailscale）

Web 画面は、自宅の PC などで起動したものを自分だけが見る使い方を想定しています。**インターネットにそのまま公開するのはおすすめしません。** 外出先のスマホから見たい場合は、[Tailscale](https://tailscale.com/)（個人利用は無料）を使ってください。ルーターのポートを開けずに、自分の端末どうしだけを暗号化した通信でつなげます。

1. PC とスマホの両方に Tailscale を入れ、同じアカウントでログインする
2. PC でアプリを起動する：`uvicorn app.main:app --host 0.0.0.0 --port 8000`（Tailscale の通信だけを受けたい場合は `--host` に PC の Tailscale の IP（100.x.x.x）を指定する）
3. スマホのブラウザで `http://<PC の Tailscale の IP>:8000` を開く

Tailscale 経由でも、念のため `.env` の `APP_USERNAME` と `APP_PASSWORD` を設定しておくと安心です。

## セキュリティ対策

| 対策 | 内容 |
|---|---|
| パスワードの保管 | SMTP のパスワードは `.env`（Git の管理対象外）か GitHub Secrets にだけ置く |
| 外部公開しない | Docker では `127.0.0.1` だけで待ち受ける。スマホからは Tailscale 経由で見る |
| Basic 認証 | `APP_USERNAME` と `APP_PASSWORD` を設定するとログインが必要になる |
| CSRF 対策 | 他のサイトから送られたフォーム（記事の削除など）を拒否する |
| ブラウザの防御 | CSP などのセキュリティヘッダーを付け、外部スクリプトの実行や埋め込みを禁止する。記事を開くときに、このアプリの URL を相手サイトに送らない |
| SSRF 対策 | フィードの URL に、社内ネットワークやクラウドの管理用アドレスを指定できない（リダイレクト先も確認する） |
| 不正なファイル対策 | 取得サイズの上限は 5MB。OPML は defusedxml で安全に読み込む |
| 依存ライブラリ | 自動テストで pip-audit を使い、既知の脆弱性を確認する。Dependabot が更新を毎週提案する |

**Gmail のおすすめ設定**：送信には、普段使いとは別の Gmail アカウントを作って使うと、万一アプリパスワードが漏れても影響を小さくできます。アプリパスワードは [Google アカウント](https://myaccount.google.com/apppasswords) でいつでも取り消せます。

## 開発

```bash
pip install -r requirements-dev.txt
pytest
```

| ファイル | 役割 |
|---|---|
| `app/main.py` | Web 画面とルーティング |
| `app/fetcher.py` | フィードの取得・解析・保存と、RSS の自動検出 |
| `app/notifier.py` | ダイジェストメールとキーワード通知 |
| `app/scheduler.py` | 定期実行（取得・通知・古い記事の削除） |
| `app/cli.py` | GitHub Actions 用のコマンド（`python -m app.cli run`） |
| `.github/workflows/` | 通知の自動実行（`notify.yml`）と自動テスト（`ci.yml`） |
| `app/presets.py` | 初期登録するジャンルとおすすめフィード |
| `app/db.py` | DB のモデル |
| `app/templates/` | 画面とメールのテンプレート |

## 注意

- RSS で取得するのはタイトル・概要・リンクだけです。本文は元のサイトで読みます。
- おすすめフィードの URL は、サイトの都合で変わることがあります。取得エラーになったフィードは「フィード管理」で修正するか削除してください。
